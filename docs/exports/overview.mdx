# Export Plugins

Export a `.bax` song from the [CLI](/docs/tools/cli) (`beatbax export <format>`), [BeatBax Desktop](/docs/tools/desktop), or the toolchain APIs. Which formats are available depends on the song’s chip.

JSON (`json`) and MIDI (`midi`) are built in for every chip and have no separate plugin guide. WAV and chip-specific tracker or register formats are documented below.
