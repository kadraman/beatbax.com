Here's how to get a built-in example song playing in minutes.

## BeatBax Desktop (recommended)

1. [Download](/download) and install [BeatBax Desktop](/docs/tools/desktop).
2. Choose **File → Open** — the file browser opens in the built-in songs directory.
3. Open a song (for example `a_trainers_journey.bax` under the `gameboy` directory).
4. The song should start playing automatically.

## BeatBax web-lite client

1. Navigate to [app.beatbax.com](https://app.beatbax.com).
2. Open **Examples** from the toolbar and pick a song (for example `a_trainers_journey.bax` listed under `Game Boy`).
3. Press **Play** in the transport bar.

## BeatBax CLI

1. Install the [BeatBax CLI](/docs/tools/cli) (`npm install -g @beatbax/cli`) — see [Installation](/docs/getting-started/installation#beatbax-cli)
2. Play a sample song, for example:

```powershell
beatbax play path\to\song.bax
```
