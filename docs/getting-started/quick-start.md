Get a built-in example song playing in minutes. If you still need to install something, see [Installation](/docs/getting-started/installation).

## Desktop (recommended)

1. [Download](/download) and install BeatBax Desktop
2. Choose **File → Open** — the file browser opens in the built-in songs directory
3. Open a song (for example `sample.bax`)
4. Press **Play** in the transport bar

## Browser

1. Open [app.beatbax.com](https://app.beatbax.com)
2. Open **Examples** from the toolbar and pick a song (for example `a_trainers_journey.bax` under Game Boy)
3. Press **Play** in the transport bar

## CLI

1. Install the CLI (`npm install -g @beatbax/cli`) — see [Installation](/docs/getting-started/installation#beatbax-cli)
2. Play a sample song, for example:

```powershell
beatbax play path\to\song.bax
```
