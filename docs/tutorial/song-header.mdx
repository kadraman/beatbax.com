# Song header

Every BeatBax song starts with a **song header**: metadata (name, artist, …) plus global directives (chip, tempo, …).

- **Metadata** defines information like the song name and its author.
- **Global directives** define overall song settings, like the sound chip or tempo.

The header for our **Tutorial Groove** song will be as follows:

```bax
song name "Tutorial Groove"
song artist "BeatBax Tutorial"
song description "Built step by step in the BeatBax Game Boy tutorial."
song tags "tutorial, gameboy"

chip gameboy
bpm 140
```

Each of these metadata or directives are used as follows:

| Directive | Purpose |
|-----------|---------|
| `song name "…"` | The title of the song - this name will be the default when creating a physical `.bax` file via `Save`. |
| `song artist "…"` | The calledomposer / artist of the song - this can be defaulted in `Settings` in BeatBax Desktop |
| `song description "…"` | A short description of the song (you can also use multiline string with `"""…"""`) |
| `song tags "…"` | Comma-separated tags - these are not used currently |
| `chip gameboy` | The sound chip to be used in the song - this is required (note: `gb` can also be used as an alias for `gameboy`) |
| `bpm 140` | The tempo of the song in beats-per-minute |

> There are other optional global directives you may use, for example `volume 0.0–1.0`, `stepsPerBar` 
(editor bar grouping). Full more details see: [Metadata directives](/docs/language/metadata-directives).
