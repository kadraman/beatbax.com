# Notes and lengths

Before defining instruments, it helps to know how pitches and timing are written in a pattern. Patterns are lists of **tokens**.

| Token | Meaning |
|-------|---------|
| `C4`, `E5`, `G#5` | A note — letter, optional sharp (`#`) or flat (`b`), then octave (scientific pitch). Default length is **1 step**. |
| `C4:4` | Same note held for **4 steps** (shorthand for `C4 _ _ _`). |
| `.` | Rest — silence; also cuts the previous note. |
| `_` or `-` | Sustain — keep the previous note sounding for one more step. |

A **step** is one timing unit at the song’s `bpm` (with default `stepsPerBar 4`, four steps make one bar). Tutorial Groove phrases are **16 steps** long so all channels stay locked together.

```bax
pat rise     = C3:16                 # hold C3 for sixteen steps
pat lead_pat = E5 . G5 C6 . G5 E5 .  # one-step notes and rests
```

More pattern tokens (`(…)`, `*N`, named drums, `inst(…)`) come later in [Patterns & sequences](/docs/tutorial/sequencing).
