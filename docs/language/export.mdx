# Export directive (deprecated)

:::warning Deprecated
The in-file `export` directive is **deprecated**. Prefer exporting from the [CLI](/docs/tools/cli) or [BeatBax Desktop](/docs/tools/desktop). Format options and plugin behaviour are documented under [Export Plugins](/docs/exports/overview).
:::

The parser still accepts the statement for older songs. Hosts may ignore it or treat it as a legacy request only.

```bax
export <format> "<path>"
```

| Part | Meaning |
|------|---------|
| `format` | Exporter id (e.g. `wav`, `uge`, `vgm`, `midi`) |
| `path` | Output path as a quoted or triple-quoted string |

```bax
# Legacy — prefer CLI / Desktop export instead
export wav "out/demo.wav"
export uge "out/demo.uge"
```
