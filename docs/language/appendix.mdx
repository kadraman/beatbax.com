## Reserved words

These identifiers cannot start a pattern-shorthand declaration (`name = …` without `pat`):

`chip`, `bpm`, `scale`, `time`, `stepsPerBar`, `ticksPerStep`, `song`, `inst`, `subpat`, `pat`, `seq`, `channel`, `effect`, `play`, `export`

## Lexical notes

| Element | Rules |
|---------|-------|
| Identifiers | `[A-Za-z_][A-Za-z0-9_\-]*` |
| Strings | `"…"`, `'…'`, or `"""…"""` (multiline) |
| Comments | `# …` or `// …` to end of line |
| Integers | Digits `[0-9]+` |
| Floats | `1`, `1.0`, `.5` |
| Notes | `[A-Ga-g][#b]?-?[0-9]+` |
| Rest/sustain | `.` `_` `-` |
| Duration | `:N` or `/N` |
| Effect suffix | `<…>` attached to a note or identifier token |
| Seq modifiers | `:name` or `:name(args)` after a sequence item |

## Deprecated directives

| Directive | Status |
|-----------|--------|
| `time` | Parsed; warns; aliases `stepsPerBar` if that was not set |
| `ticksPerStep` | Parsed; warns; **no effect** (fixed engine tick resolution) |
